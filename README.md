# Urban Hairplaza

**Premium Barbershop & Home Service Booking Platform**  
Location: Near Phanishwar Narh Renu Statue, Simraha, Araria – 854331, Bihar

## Quick Start

```bash
npm install
cp .env.example .env
# Fill in your .env credentials
npm run dev    # Development (nodemon)
npm start      # Production
```

Browse: http://localhost:7890

## Pages
- `/` — Homepage
- `/services.html` — All services
- `/barbers.html` — Our barbers
- `/gallery.html` — Photo gallery
- `/visualizer.html` — AI Hairstyle Visualizer
- `/about.html` — About Us
- `/contact.html` — Contact form
- `/book.html` — 5-step booking wizard
- `/login.html` — OTP login
- `/profile.html` — User profile & booking history
- `/admin/login.html` — Admin login
- `/admin/dashboard.html` — Admin dashboard

## Stack
- **Frontend:** HTML5, CSS3, Vanilla JS
- **Backend:** Node.js + Express (port 7890)
- **Database:** PostgreSQL (Neon/Supabase)
- **Payments:** Cashfree Payment Gateway
- **SMS:** Twilio
- **WhatsApp:** CallMeBot
- **AI:** OpenAI GPT-4o + DALL-E 3
